## v0.1.6

**Fix: deleting a list no longer shows a false error**

Deleting a list from the SmartLists page (single or bulk) worked, but the page showed "Failed to delete list ...: HTTP undefined: undefined" because the server's empty success reply was read as a failure. It now shows the normal success message.

Also includes everything from 0.1.5: the **Next Up** template, the empty **Library Name** rule in the Next Up and Continue Watching templates, whole-name matching for Library Name **is in** / **is not in** (so `TV` no longer matches `Kids TV`), and the fix that stops a template list being created while its Library Name is still empty.

Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
