## v0.1.8

**Security: images are now decoded with TIFF turned off**

New advisories published on 2026-10-07 affect the image library the plugin uses (ImageSharp 3.1.12); the fixes exist only in the 4.x line, which needs a paid license. The affected code is the TIFF decoder and encoders (plus two parts the plugin does not use), so the plugin no longer decodes TIFF at all, and TIFF uploads are refused. JPEG, PNG, GIF, WebP and BMP covers work as before. A crafted 24-byte BigTIFF that keeps the default decoder busy indefinitely is rejected in milliseconds.

**Releases are now published automatically**

Pushing a version tag builds the DLL and creates this release, with these notes.

Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
