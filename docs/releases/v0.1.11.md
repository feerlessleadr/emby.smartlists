## v0.1.11

**Security fixes from a review of the plugin**

- The Status page no longer lets text in a refresh error message (which can include a list's regex) break out of an HTML attribute.
- Restoring a backup now validates each list like a created one, ignores the Emby playlist and collection ids stored in the zip (a restore that overwrites a list keeps the ids this server already has), and compares ids in a canonical form, so a backup can no longer replace a list it was meant to skip or point a list at an unrelated playlist.
- Creating a list with an `Id` that already exists now answers 409 instead of replacing it; a non-GUID `Id` answers 400.
- The "similar to" rule's regex now has the same match timeout and cache as the other regex rules, and the regex cache is capped.
- Cover pictures are decoded with limits: files over 50 MB or 40 megapixels are skipped after reading only the header, only the first frame of an animation is read, and decoder memory is capped.

Details and what was left as is: `docs/security.md`. Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
