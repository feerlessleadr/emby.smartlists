## SmartLists for Emby v0.1.1

A page-layout polish release. No changes to list building, refresh, API or stored data, so upgrading is safe.

### Changed
- **Tab bar:** *Create List / Manage Lists / Status / Settings* now sit on a compact shaded bar that is only as wide as its buttons, with rounded ends and a clearly highlighted active tab.
- **Dropdowns match text boxes:** every dropdown (template, list type, media types, rule field and operator, sort options, playlist users, default settings) is now the same height as the text boxes.
- **No more "floating" controls:** the rule field picker, media type pickers, users picker and the Tags box now have the same background, border and rounded corners as the other fields.
- **Rules and sort sections:** each rule group, rule row, the "Max items" strip and each sort option is its own tinted panel, so the sections no longer blend into one big box. Colours follow Emby's light and dark themes.
- **Spacing and text:** more space between *Playlist Users*, the *All users* checkbox and the dropdown below; the *Overview* text area now lines up with the other text boxes; dropdown text sizes are consistent; the Bumper media type dropdown is full width.

### Install / upgrade
(superseded by v0.1.2: the plugin is now a single self-contained DLL.) Extract both DLLs from `Emby.Plugin.SmartLists-0.1.1.zip` into Emby's `plugins` folder and restart Emby (or let your plugin installer do it). Hard-refresh the dashboard page afterwards.
