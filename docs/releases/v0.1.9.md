## v0.1.9

**New: a documented API, ready for apps**

The plugin's HTTP API (the one the admin page uses) is now documented in `docs/api.md`, and two endpoints were added so other clients, such as the upcoming Emby SmartLists Android app, can use it without copying the web page's logic:

- `GET /Plugins/SmartLists/info` returns the plugin version and an API version a client can check.
- `GET /Plugins/SmartLists/catalog` returns every rule field with its input type, operators and allowed values, plus the sort options, media types and date/value formats.

Nothing existing changed; the admin page works as before. Like the rest of the API, both need an Emby administrator's access token.

Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
