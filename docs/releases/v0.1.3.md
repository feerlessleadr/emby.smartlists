## SmartLists for Emby v0.1.3

### Fixed
- **The rule *Field* dropdown stopped opening** after you left the page and came back (for example creating a list, browsing the playlist in another Emby tab, then returning to create another). Only a page reload fixed it. The dropdown's click handlers were tied to a per-rule cancellation signal that gets cancelled and replaced when the page is shown again, which silently disconnected them. They now live with the dropdown itself.
- **Custom cover images did not show when editing a list**, and clicking the image name led to "Access token is invalid or expired". The browser was requesting the image without Emby's login token. The edit form's thumbnail and the image links (edit form and *Manage Lists* details) now load the image with your session token and display it.

### Install / upgrade
Replace `Emby.Plugin.SmartLists.dll` (single self-contained file; no other files needed). Hard-refresh the dashboard page afterwards.
