## v0.1.10

**New: preview a list before saving it**

- `POST /Plugins/SmartLists/preview` runs a list's rules without saving the list or touching anything in Emby, and returns how many items match plus a description of the first ones (default 25, at most 100). It takes the same body as creating a list. The Emby SmartLists Android app uses it for its "Preview what matches" button.
- Documented in `docs/api.md` ("Preview (dry run)"). The API version stays 1: the change only adds a call.

Nothing existing changed; the admin page works as before.

Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
