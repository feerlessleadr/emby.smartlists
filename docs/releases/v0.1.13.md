## v0.1.13

**Fixed: a tag on an album now matches that album's tracks**

- An Audio smart playlist that uses Tags with either parent option ("also check parent tags" or "only check parent tags") now sees a tag stored on the album. Emby keeps the album as its own item, separate from the folder the audio files sit in, and the plugin was only looking at the folder. Both options used to return nothing when the tag was on the album and not on the tracks.
- The same album is included for parent studios, parent genres, and parent favorites.
- "Contains" and "is" both match. A tag that is only on the album still does not match when the parent option is left off.

The API version stays 1. Nothing else in the list format changed.

Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
