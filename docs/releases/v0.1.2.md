## SmartLists for Emby v0.1.2

Fixes updating the plugin in place (for example with a GitHub plugin installer) while Emby is running.

### Fixed
- **Upgrade failed with "The process cannot access the file ...SixLabors.ImageSharp.dll because it is being used by another process."** The image library was shipped as a second DLL next to the plugin and held open by the running server, so it could not be replaced. It is now **embedded in `Emby.Plugin.SmartLists.dll`** and loaded from memory, so the plugin is a **single self-contained file** that can be replaced while Emby runs. Cover generation (collage and badge) is unchanged.

### Upgrading from 0.1.0 / 0.1.1
- The upgrade that fails is the one *from* 0.1.1, because the old copy of the image DLL is still locked. **Stop Emby once, replace `Emby.Plugin.SmartLists.dll` with the file from this release, start Emby.** After that, future updates (manual or through the installer) work without stopping the server.
- A loose `SixLabors.ImageSharp.dll` left in the `plugins` folder from earlier versions is no longer used by this plugin. You can delete it, unless another plugin of yours uses it.
- Install note: this release has a single asset, `Emby.Plugin.SmartLists.dll`, with no zip.

No changes to lists, settings, the API or stored data.
