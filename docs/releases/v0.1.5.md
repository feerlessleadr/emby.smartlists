## v0.1.5

**New: "Next Up" template**

A new playlist template, **Next Up**: the next unwatched episode of each show you are part-way through, with the show you watched most recently first. Shows you have never started and shows you have finished are left out. It uses the Next Unwatched rule with **Include unwatched series** set to No, and the Most Recently Watched Round Robin sort (added in 0.1.4), grouped by series name. The option can still be changed after choosing the template.

Both **Next Up** and **Continue Watching** now come with an empty **Library Name** rule: type each library you want and press Enter before creating the list (creating the list is blocked until it is filled in). Library names are matched whole, so `TV` does not also match `Kids TV` (the **is in** / **is not in** operators on Library Name now compare whole names; **contains** still matches part of a name).

The **Continue Watching** template still includes the first episode of shows you have not started.

Existing lists are not changed. On a list you built yourself, set **Include unwatched series** to **No** on the Next Unwatched rule to get the same behaviour.

Upgrade note: replace the single `Emby.Plugin.SmartLists.dll` and restart Emby.
